CONFIGURAÇÃO DO BANCO SUPABASE & CHAVES DE API

Como Executar os Comandos SQL, Obter as Credenciais e Configurar o Arquivo .env

Documento de apoio prático para estudantes do Ensino Médio Técnico em Informática. Aprenda do zero a criar um projeto no Supabase, rodar o script de criação da tabela de tarefas (DDL) e configurar as chaves de acesso no arquivo .env para conectar seu aplicativo Python com o Flet.

Disciplina: Linguagens de Programação
Curso: Técnico em Informática Integrado ao Ensino Médio
Plataforma: Supabase (PostgreSQL na Nuvem) + python-dotenv
Projeto Alvo: 08_tarefas_mvc_supabase/

1. O que é o Supabase e por que o utilizamos?

O Supabase é uma plataforma moderna na nuvem (conhecida como alternativa livre ao Google Firebase) que nos fornece um banco de dados relacional PostgreSQL completo, gratuito e pronto para uso.

Em vez de termos que instalar o PostgreSQL na máquina de cada aluno, configurar portas de rede ou servidores locais, o Supabase nos entrega uma URL e uma Chave de Acesso que permitem que o nosso programa Python salve e consulte dados pela internet com máxima facilidade e velocidade.

🎯 O Objetivo Deste Tutorial:

Ao final deste guia, você terá:
  1. Criado um projeto gratuito no Supabase;
  2. Executado o script SQL no SQL Editor para criar a tabela tarefas;
  3. Copiado a Project URL e a Chave Anon/Public;
  4. Criado e preenchido o arquivo .env na pasta do seu projeto Python.

2. Parte 1: Criando o Projeto no Supabase

1 Acessar o Painel do Supabase

Abra o navegador de sua preferência e acesse o site oficial:
👉 https://supabase.com

Clique no botão verde "Start your project" ou em "Sign In". Você pode fazer login diretamente com a sua conta do GitHub ou com o seu e-mail do Google institucional.

2 Criar uma Nova Organização e Projeto

Após entrar no painel (Dashboard), clique no botão verde "New Project" (Novo Projeto). Preencha o formulário com os seguintes dados:

  • Name (Nome do Projeto): Digite por exemplo tarefas-flet ou sistema-tarefas-mvc;
  • Database Password (Senha do Banco): Crie uma senha forte e anote-a em um bloco de notas seguro (ou clique em Generate a password e copie);
  • Region (Região do Servidor): Escolha a região mais próxima do Brasil, como São Paulo (sa-east-1) ou US East (N. Virginia);
  • Pricing Plan (Plano): Selecione Free Tier (Gratuito).

Clique em "Create new project". O Supabase levará cerca de 1 a 2 minutos para preparar e provisionar o seu banco de dados na nuvem. Aguarde até a tela inicial do projeto carregar!

3. Parte 2: Executando o Script SQL no SQL Editor

Para que o nosso código Python consiga salvar tarefas, precisamos criar a tabela tarefas dentro do PostgreSQL do Supabase. Nós fazemos isso usando o SQL Editor integrado da plataforma.

3 Abrir o SQL Editor

No menu lateral esquerdo do painel do Supabase, procure pelo ícone de um terminal com a sigla `>_` ou pelo texto SQL Editor e clique nele.

Em seguida, clique no botão "New query" (ou no botão +) para abrir uma nova janela em branco de comandos SQL.

4 Colar e Executar o Script SQL

Copie exatamente o código SQL abaixo (que também está salvo no arquivo database/schema.sql do seu projeto): 

-- 1. Criação da tabela de tarefas
CREATE TABLE IF NOT EXISTS tarefas (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nome TEXT NOT NULL,
    tipo TEXT NOT NULL DEFAULT 'Comum',
    xp INT NOT NULL DEFAULT 10,
    concluida BOOLEAN NOT NULL DEFAULT FALSE,
    criado_em TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 2. Habilita o sistema de segurança do PostgreSQL
ALTER TABLE tarefas ENABLE ROW LEVEL SECURITY;

-- 3. Cria a política que permite SELECT, INSERT, UPDATE e DELETE pela chave anon
CREATE POLICY "Permitir acesso completo a tarefas" ON tarefas
    FOR ALL
    USING (true)
    WITH CHECK (true);

Cole este script dentro do editor e clique no botão verde "Run" (ou pressione o atalho Ctrl + Enter).

✅ Se tudo der certo, você verá a mensagem verde no rodapé: "Success. No rows returned". A sua tabela foi criada com sucesso!

5 Confirmar a Criação no Table Editor

No menu lateral esquerdo, clique no ícone de tabela chamado Table Editor. Você verá a tabela tarefas listada com as colunas: id, nome, tipo, xp, concluida e criado_em prontas para receberem registros!

4. Parte 3: Coletando as Chaves de API e Criando o Arquivo .env

Para que o nosso programa Python saiba onde o banco está e tenha permissão de gravar dados, precisamos pegar duas informações secretas: a URL do Projeto e a Chave Anon/Public.

6 Localizar as Chaves de Conexão: Project Settings ➔ API Keys

No menu lateral esquerdo do painel do Supabase, siga exatamente esta rota:

  1. Clique no ícone de Engrenagem (Project Settings) na parte inferior do menu lateral esquerdo;
  2. Dentro do menu CONFIGURATION, clique na opção API Keys (caminho: Project Settings ➔ API Keys);
  3. É exatamente nesta tela que você acessa a sua Publishable key (ou chave pública)!

📍 Onde Fica Cada Informação no Painel:

  • Publishable key: Acessada diretamente em Project Settings ➔ API Keys. Ela começa com o prefixo sb_publishable_.... É ela que você copia para a variável SUPABASE_KEY no seu arquivo .env.
  • Legacy anon key: Se preferir a chave antiga (em formato JWT eyJhbG...), ela fica na mesma tela, na aba ao lado chamada Legacy anon, service_role API keys.
  • Project URL: No menu lateral esquerdo, clique em Data API. Lá você verá o campo URL.
    ⚠️ ATENÇÃO COM O FINAL DA URL: O painel do Supabase exibe a URL com /rest/v1/ no final (ex: https://fulwfzlynmazwemlhyki.supabase.co/rest/v1/). O Python precisa apenas da URL base (sem o /rest/v1/).
    Dica: O nosso código Python já foi programado para limpar o /rest/v1/ automaticamente caso você esqueça, mas o ideal é deixar apenas https://seu-id.supabase.co!
Campo no Painel do Supabase O que é e para que serve? Variável correspondente no .env
Project URL (em Data API) O endereço web único do seu banco (ex: https://fulwfzlynmazwemlhyki.supabase.co) SUPABASE_URL
Publishable key (ou anon public) A chave pública segura que autoriza o Flet a ler e gravar tarefas SUPABASE_KEY

⚠️ ATENÇÃO MÁXIMA COM A CHAVE SECRETA:

Copie apenas a chave rotulada como Publishable key (ou anon public).
NUNCA copie ou utilize a chave Secret keys / service_role no aplicativo do aluno! A chave secreta ignora todas as regras de segurança e nunca deve ser exposta.
7 Criar o Arquivo .env no Projeto Python

Agora volte para o seu computador no VS Code (ou Antigravity) dentro da pasta:
C:\Users\alyso\Documents\python\POO_FLET\08_tarefas_mvc_supabase\

  1. Na raiz dessa pasta, crie um novo arquivo com o nome exato .env (com um ponto na frente e sem extensão .txt);
  2. Abra o arquivo .env e digite a seguinte estrutura, colando as suas chaves reais logo após o sinal de igual (sem aspas e sem espaços):
SUPABASE_URL=https://seu-codigo-aqui.supabase.co
SUPABASE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.sua_chave_anon_aqui

Salve o arquivo pressionando Ctrl + S.

💡 Por que usamos o arquivo .env?

O arquivo .env (Environment / Ambiente) é uma convenção mundial na programação. Ele permite que cada desenvolvedor tenha suas próprias credenciais no seu computador sem misturá-las com o código do sistema. Quando você envia o projeto para o GitHub, o arquivo .env nunca é enviado (ele é ignorado pelo .gitignore), protegendo o seu banco contra invasões!

5. Parte 4: Testando a Conexão de Ponta a Ponta

Com o script SQL executado e o arquivo .env salvo, o seu sistema está 100% configurado! Para comprovar o funcionamento:

  1. Abra o terminal na pasta do projeto: 
    cd "C:\Users\alyso\Documents\python\POO_FLET\08_tarefas_mvc_supabase"
  2. Execute o comando de inicialização do programa: 
    python main.py
  3. A tela do Flet irá abrir com o ícone verde de nuvem: "Tarefas com MVC + Supabase"!
  4. Cadastre uma tarefa (ex: "Apresentar projeto de POO").
  5. Vá no seu navegador, abra o Table Editor do Supabase e atualize a página: a sua tarefa estará salva nas linhas do banco de dados na nuvem!
