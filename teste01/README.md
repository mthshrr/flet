# teste01 - Aplicativo Flet

Este projeto é um aplicativo simples desenvolvido com a biblioteca Flet. O aplicativo possui uma interface de usuário que permite a entrada de dois números e a execução de uma ação ao clicar em um botão.

## Estrutura do Projeto

```
teste01
├── src
│   ├── main.py        # Ponto de entrada do aplicativo
│   ├── ui.py          # Define a interface do usuário
│   └── components
│       └── __init__.py # Para componentes adicionais no futuro
├── requirements.txt    # Dependências do projeto
├── .gitignore          # Arquivos a serem ignorados pelo Git
└── README.md           # Documentação do projeto
```

## Instalação

Para instalar as dependências do projeto, execute o seguinte comando:

```
pip install -r requirements.txt
```

## Uso

Para iniciar o aplicativo, execute o arquivo `main.py`:

```
python src/main.py
```

A interface do usuário permitirá que você insira dois números e clique em um botão para realizar uma ação com esses números.
